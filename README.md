# SABUYPOS Downloads

ดาวน์โหลดไฟล์ติดตั้ง SABUYPOS อย่างเป็นทางการสำหรับ Android, macOS และ Windows

**[ดาวน์โหลดรุ่นล่าสุด](https://github.com/chaiwatttt2/sabuypos-downloads/releases/latest)**

| ระบบ | วิธีติดตั้ง |
|---|---|
| Android | ดาวน์โหลดไฟล์ `.apk` แล้วติดตั้งบนอุปกรณ์ Android |
| macOS | ดาวน์โหลด ZIP แล้วแตกไฟล์แอป รุ่น 1.1.3 (811) เซ็นด้วย Developer ID และผ่าน Apple notarization |
| Windows | แตก ZIP ทั้งโฟลเดอร์ แล้วเปิด `sabuypos.exe` ต้องมี Microsoft Visual C++ Redistributable (x64) ตัวแอปเปิดระบบขายผ่านเว็บ SABUYPOS |
| iPhone / iPad | ติดตั้งผ่าน TestFlight สำหรับผู้ทดสอบที่ได้รับเชิญ ขณะนี้ยังไม่เปิด App Store สาธารณะ ไม่มีไฟล์ iOS สำหรับติดตั้งผ่าน GitHub |

ตรวจสอบชื่อรุ่นและค่า SHA-256 จาก `SHA256SUMS.txt` ของแต่ละ release ก่อนใช้งาน

เว็บไซต์: https://www.sabuypos.com/ · หน้าดาวน์โหลด: https://pos.sabuypos.com/downloads/

Repository นี้มีเฉพาะข้อมูลการแจกจ่ายและไฟล์ติดตั้ง ไม่มีซอร์สโค้ดแอปหรือข้อมูลร้านค้า การดาวน์โหลดไฟล์ไม่ได้ให้สิทธิ์เข้าถึงบัญชีร้านหรือแพ็กเกจแบบชำระเงิน
